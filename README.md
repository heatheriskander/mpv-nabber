# mpv-nabber
mpv script to nab clips that should work on most platforms with ffmpeg.

## Usage
1. Press `n` to enable nabber.
2. Seek to the start of your clip and press `i`.
3. Seek to the end of your clip and press `o`.
4. Press `p` to nab the clip. Give it a name or press `enter` to use the default. Currently, this will silently overwrite an existing clip with the same name—this encourages discipline and careful attention and builds character.
5. Find your clip in `~/clips/`!
